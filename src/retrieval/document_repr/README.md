# document_repr 文档多视图表示

## 目标

该模块把一篇长指南转换为适合文档级召回的紧凑表示。所有视图共享 `doc_id`，每条视图使用独立 `view_id` 和 `view_type`，检索后再聚合回文档。

| 文件 | 作用 |
| --- | --- |
| `builder.py` | 从标题、摘要、章节和推荐块提取信号，构建 document card 与 views |
| `section_classifier.py` | 判断章节属于范围人群、推荐、PICO、方法或其他类型 |
| `__main__.py` | 命令行入口 |

## 主要视图

- 文档卡片：标题、机构、日期、摘要和质量字段的统一表示。
- `scope_population`：疾病范围、适用人群和临床场景。
- `recommendation_summary`：优先收集推荐语句和关键结论。
- `pico_questions`：问题、人群、干预、比较和结局相关文本。
- 其他视图用于补充方法、背景或结构信号，具体以 builder 输出为准。

## 构建规则

- 候选片段先按章节类型、内容质量和长度排序，再在预算内拼接。
- 推荐视图达到信息量后会提前停止，避免长指南生成过大的召回文本。
- card 和 view 必须保留来源路径、日期、机构、科室及清洗质量字段。
- 修改视图文本或 `view_id` 规则后，需重建 SQLite/FAISS/PostgreSQL 对应索引和向量。

## 验证

抽样检查每篇文档是否至少拥有卡片以及必需视图，并确认相同 `doc_id` 下没有重复 `view_id`。
